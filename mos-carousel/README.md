# Вкусная Москва — отдельный прототип карусели

На macOS запусти `start.command` двойным кликом. Нужен Python 3. Откроется браузер; оставь окно терминала работающим. Остановка — Ctrl+C. Альтернатива из папки проекта: `python3 preview.py`.

Прямое открытие index.html через file:// не подходит: браузеру нужен локальный HTTP-сервер для JS-модулей и текстур. Все библиотеки, фотографии и шрифты включены; после распаковки интернет не требуется.

Пять карточек образуют наклонённое кольцо. Автовращение делает оборот примерно за 140 секунд. Наведение на переднюю карточку ставит вращение на паузу. Перетаскивание вращает кольцо с инерцией; после отпускания пауза наведения возвращается через 1,1 секунды, чтобы дать инерции отработать. Клик не выполняет переход. С клавиатуры: Tab до карусели, затем ←/→. Системное уменьшение движения отключает автовращение.

Композиция 1600×981 пропорционально масштабируется под ширину окна. Отдельная мобильная версия не проектировалась. Шапка — визуальный макет.

Заголовок: локальный Roboto Flex, 280px/80%, 600, #DF2836. Оси `opsz:144`, `wdth:25` подобраны по скриншоту, letter-spacing −1px. Подписи — Dela Gothic One из исходного проекта.

Настройки: `carousel.js` — радиус, высота/дуга карточек, наклон и список изображений; `motion.js` — скорость и инерция; `styles.css` — композиция и типографика.

Проверки модели вращения: открой `/tests/` на том же локальном сервере. Семь тестов: автовращение, пауза, независимость от FPS, drag и инерция, завершение drag, уменьшение движения, длинный кадр.

Three.js 0.180.0, MIT: https://github.com/mrdoob/three.js . Исходные фотографии и иконки взяты из соседней папки mos-eda. Она не изменялась.

Якорная навигация по Figma 357:33093: слева x83/y684, пять пунктов без ссылок и действий по клику. При наведении полоска расширяется с 20 до 40px, текст сдвигается вправо на 20px; клавиатурный фокус показывает то же состояние.

Уточнение типографики: якоря 16px/20px, описание 16px/24px.
