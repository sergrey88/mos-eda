# Вкусная Москва

Десктопный интерактивный главный экран. HTML, CSS и JavaScript без сборки.

Все файлы страницы, фотографии и шрифты находятся в отдельной папке [`mos-eda/`](mos-eda/). Для локального просмотра открой `mos-eda/index.html` в браузере.

## Публикация

В Settings → Pages выбери **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.

После публикации: https://sergrey88.github.io/mos-eda/

Корневая страница перенаправляет в `mos-eda/`. Файл `.nojekyll` отключает обработку Jekyll.
