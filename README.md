# Вкусная Москва

Десктопный интерактивный главный экран. HTML, CSS и JavaScript без сборки.

Все файлы страницы, фотографии и шрифты находятся в отдельной папке [`mos-eda/`](mos-eda/). Для локального просмотра открой `mos-eda/index.html` в браузере.

## Публикация

В Settings → Pages выбери **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.

После публикации: https://sergrey88.github.io/mos-eda/

Корневая страница перенаправляет в `mos-eda/`. Файл `.nojekyll` отключает обработку Jekyll.

## Вариант с 3D-каруселью

Актуальный отдельный прототип находится в [`mos-carousel/`](mos-carousel/): вращающееся кольцо из изогнутых карточек, перетаскивание с инерцией, пауза при наведении, якорная навигация без ссылок. Композиция обновлена по Figma: описание справа — Geologica Light 18 px, якорная навигация — 20 px, круговой указатель слева внизу.

Для локального запуска: `python3 mos-carousel/preview.py` или `mos-carousel/start.command` на macOS. Все ресурсы включены, установка зависимостей не нужна.

Адрес после публикации GitHub Pages: https://sergrey88.github.io/mos-eda/mos-carousel/

Предыдущий вариант в `mos-eda/` сохранён.
