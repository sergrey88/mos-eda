# Вкусная Москва — карусель 3

Новый отдельный экран по Figma 536:23956. HTML/CSS/JS без сборки и зависимостей; предыдущие версии не менялись.

Запуск на macOS: двойной клик start.command или python3 preview.py. Обновление страницы повторяет вступление. Все ресурсы локальные; file:// не подходит для JS-модулей.

Заголовок проявляется с подъемом за .9с. С .9с 11 карточек последовательно заходят снизу слева по часовой стрелке и собираются за 4.2с. Скорость спокойного вращения 4.4°/с. Первая фотография проявляется у нижнего края кадра сразу после заголовка, без скрытого проезда за экраном. Ссылки, описание и кнопка появляются одновременно с ней. Надпись кнопки вращается за 20с, центр неподвижен; ховеры из mos-carousel-2.

Композиция 1600×901 масштабируется по ширине, сцена продолжается до низа окна на высоких экранах. Каждая карточка перекрывает предыдущую и заходит под следующую, включая замыкание кольца. Перетаскивание мышью вращает круг с затухающей инерцией; также доступны ←/→ после фокуса на сцене. Отдельного мобильного макета нет. Первый якорь и круглая кнопка прокручивают страницу к ярмаркам. При reduced motion вступление и вращение отключаются; при скрытии вкладки анимации приостанавливаются.

Проверки: node tests/orbit.mjs; в браузере /tests/integration.html.

Просмотр: https://sergrey88.github.io/mos-eda/mos-carousel-3/

Шапка скопирована с mos.ru: оригинальные CSS, логотип, иконки и Golos Text. Шапка сохраняет собственную высоту 64px и адаптивные пороги, независимо от масштаба hero. По запросу пользователя все действия отключены: нет переходов, поиска, авторизации и раскрытия меню; сохранены только ховеры. Содержимое подменю не переносилось.

Масштабирование: композиция 1600×840 равномерно вписывается по ширине и высоте окна под шапкой 64px, по горизонтали центрируется. Минимальная общая высота экрана 800px; ниже этого размера масштаб сохраняется и появляется вертикальная прокрутка. На высоких окнах сцена продолжается до нижнего края. Проверки: node tests/layout.mjs.

Наведение на «Рыбные рынки»: карточка 06 за 0.7с по часовой стрелке с замедлением в конце доворачивается в верхний центр, останавливается и показывает зацикленное видео без звука. При уходе курсора возвращаются фотография и обычное вращение. То же доступно при клавиатурном фокусе. Во время вступления запрос ожидает завершения сборки круга. Проверки: node tests/fish-focus.mjs и /tests/fish.html.

Видео проявляется и исчезает за 320мс. При уходе курсора продолжает воспроизведение до завершения фейда, затем останавливается и сбрасывается.

Локально добавлены блоки Figma 578:31235: Московские ярмарки, специальные предложения, эксклюзивные продукты и новости. Переход по раскадровке 578:32931 привязан к скроллу в обе стороны: главный экран открывает закреплённый яблочный фон, белый блок поднимается поверх него. Заголовок, описание и категории ярмарок проявляются самостоятельно за 800мс после достижения порога прокрутки. Категории — статичные плашки без ховеров и кликов. Назначения «Где купить», «Читать» и дополнительных слайдов не заданы в прототипе. Эти изменения опубликованы вместе с основным прототипом на GitHub Pages.

Проверки новых блоков: node tests/fairs-scroll.mjs и в браузере /tests/fairs.html. Все изображения и SVG взяты из макета и хранятся локально.

Последующие блоки используют масштаб главного экрана, включая ограничение по высоте окна, и центрируются относительно той же сетки. На ховере карточек предложений и эксклюзивных продуктов изображение плавно увеличивается до 1.1 внутри своего фрейма; курсор — pointer. Категории ярмарок остаются без ховеров.
