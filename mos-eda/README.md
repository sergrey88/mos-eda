# Вкусная Москва

Открой `index.html` в браузере. Сборка и интернет не нужны: фотографии, иконки и шрифты лежат в `assets/`.

Только десктоп. Композиция Figma 1600×1210 масштабируется без перестроения элементов, а сцена и шапка занимают всю ширину окна. Карточки не обрезаются внутренним фреймом. Двигай мышь, чтобы перемещать карточки; наведи на карточку для увеличения. Клик не выполняет переход.

Механика Snog Productions: параллакс ±30vw/vh, инерция 90%, дополнительные слои глубины, увеличение 1.4 за 300 мс, передний план. Все нижние заголовки одного размера, плавно поднимаются снизу и уходят вниз. Курсор — белый круг 160×160 с надписью «Подробнее» по Figma 346:32370. При включённом системном уменьшении движения параллакс и анимация заголовков отключены.
