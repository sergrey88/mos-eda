# Вкусная Москва — карусель 2

Отдельная версия по Figma357:33535 с плоскими карточками и механикой ONY. Предыдущие версии не изменены.

На macOS дважды нажми `start.command`. Нужен Python3; оставь терминал открытым, остановка — Ctrl+C. Или выполни из папки `python3 preview.py`.

Открывай через локальный сервер: прямое открытие `index.html` через file:// не загружает JS-модули. Все фотографии, иконки и шрифты включены, интернет после скачивания не нужен.

Заголовок поднимается из прозрачности за0.9с. С0.75с начинают появляться карточки снизу, описание и якоря. За3.3с карточки собираются в орбиту и продолжают вращение — один оборот примерно82с. Заголовок остаётся на экране. Для повтора вступления обнови страницу.

Якоря —16px/20px, описание —16px/24px.

Перетаскивай сцену мышью в нужную сторону: вращение продолжается с инерцией. С клавиатуры: Tab до сцены, затем ←/→. Клик карточки и якоря не выполняет переход: назначения и нижние разделы в этом прототипе не заданы. При наведении и фокусе полоски якорей расширяются.

При системном уменьшении движения вступление и автоматическое вращение отключены; ручное управление доступно. При скрытии вкладки движение и вступление приостанавливаются.

Композиция1600×901 пропорционально масштабируется по ширине. Отдельная мобильная версия не проектировалась.

Настройки: `orbit.js` — траектория по макету, размеры, тайминг вылета, скорость и инерция; `carousel.js` — загрузка, слои, управление; `styles.css` — композиция, типографика, появление текста. Фотографии — локальные оригиналы из Figma, десять видимых изображений.

Проверки на локальном сервере: `/tests/` — модель орбиты; `/tests/integration.html` — появление, ресурсы, слои и reduced motion.

Макет: https://www.figma.com/design/9uLG24IrW2pbpWZzFHysg1/?node-id=357-33535
Референс движения: https://ony.ru/

Обновлённая композиция: описание и якоря слева вверху (16px), более крутая орбита с полупрозрачным дальним планом и прямыми углами карточек. Круассан между строками заголовка экспортирован из Figma с прозрачностью, точной обрезкой и цветокоррекцией.

Надпись круглой кнопки вращается по часовой стрелке:20с на оборот, бесконечно, линейно. Стрелка и внутреннее кольцо неподвижны. При reduced motion надпись не вращается. Назначение перехода кнопки пока не задано, клик не выполняет действие.
